# **App Name**: FeedbackFlow

## Core Features:

- Feedback Submission: Allow users to submit feature requests with rich text descriptions and attachments.
- Voting and Commenting: Enable users to vote on feedback and add comments.
- Public Roadmap: Display a public roadmap showing the status of planned features.
- Changelog: Display a changelog of released features and updates.
- Admin Dashboard: Provide an admin dashboard to manage feedback, users, and settings.
- AI-Powered Feedback Analysis: Use a tool to automatically categorize and prioritize feedback using sentiment analysis.
- Data Storage: Store and retrieve feedback data using Firestore.

## Style Guidelines:

- Primary color: HSL(214, 83%, 49%) -> RGB(#3B82F6), a vibrant blue to reflect trustworthiness and innovation.
- Background color: HSL(219, 22%, 96%) -> RGB(#F0F5FA), a light gray for a clean and modern look.
- Accent color: HSL(184, 55%, 45%) -> RGB(#38B2AC), an analogous color providing a calm and supportive feel.
- Body and headline font: 'Inter' (sans-serif) for a modern and readable interface.
- Code font: 'Source Code Pro' for displaying code snippets.
- Use simple, clear icons to represent feedback categories and actions.
- Maintain a clean and organized layout with a focus on readability.
